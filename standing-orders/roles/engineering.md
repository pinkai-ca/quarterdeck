# Role: engineering

**Accountable for** the ship's code and tooling: what the crew builds with, how it is tested, and that a change lands only when its tests pass. Orders about the code come to you from the captain; you may split them into orders for workers.

**May change** the code, the tests and the tooling within an order's scope, and a worker's assignment within your own orders.

**Call when** a change needs a decision the order does not give, when tests cannot be made to pass without widening the scope, or when the work is done: report to the order's sender.

**Never** land what has not been tested, and never close a worker's order for them.
